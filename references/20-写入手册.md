# 写入手册（`cli.mjs`）

> 老板在聊天框里说「这一步完了，存进去」，我（AI）就把产出组织成一份 payload，一次 `save` 写进库。
> **本文件的示例可直接照抄改字段，不要自己发明新字段。**

> **名字澄清（老板 2026-10-23 问过）：`save` 跟 git 一点关系都没有。**
> 它只是「把这一批数据写进 SQLite」的动词，不开仓库、不存快照、不产生版本历史。
> 整个 `D:\vibe-mv\` 与 `D:\vibe-mv-文件库\` 都没有 `.git`，作品数据从未进过 git。

## 0. 一句话心智模型

**一个 payload = 一关的全部产出 = 一个事务。** 全进或全不进，绝不留下半截数据。

```
node scripts/cli.mjs save --file payload.json
```

## 2. `save` 的 payload

### 2.1 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `slug` | ✅ | 哪首歌。不存在则报错（先 `new-song`） |
| `gate` | ✅ | 这一步属于哪一关：`G0`…`G5`。`G3.5` 照写 |
| `stage` | ⬜ | 这一关的整体状态与备注 |
| `song` | ⬜ | 顺带更新歌曲信息（时长/BPM/引擎/画幅） |
| `artifacts` | ⬜ | 产物文件列表 |
| `assets` | ⬜ | 资产定义 |
| `images` | ⬜ | 图（含提示词、seed、成本） |
| `svgs` | ⬜ | SVG 代码 + 落盘路径 |
| `skillRuns` | ⬜ | 这一步用了哪些技能 |
| `decisions` | ⬜ | 老板这一步做的决定 |
| `costs` | ⬜ | 这一步花掉的钱 |

**空数组等于没写**，不报错。只有 `slug` 与 `gate` 是硬要求。

### 2.2 完整示例（照这个改）

```json
{
  "slug": "jiaowo-laowangba",
  "gate": "G3.5",
  "stage": { "status": "partial", "note": "18 件判完，8 件 ai / 10 件 svg" },
  "assets": [
    { "asset_key": "turtle", "name": "老乌龟", "cat": "角色",
      "angle": "背视", "channel": "ai", "status": "draft",
      "spec_json": { "palette": ["#2F6B4F", "#8FBF7A"], "parts": 1 } }
  ],
  "images": [
    { "asset_key": "turtle", "path": "images/turtle/turtle-03.png",
      "kind": "ref", "w": 1024, "h": 1024,
      "prompt": "扁平矢量插画，一只老爷爷形象的老乌龟，背视……",
      "seed": 1234567890, "workflow": "rh2", "cost": 0.12 }
  ],
  "artifacts": [
    { "gate": "G3.5", "kind": "relay", "path": "storyboard/relay.md" }
  ],
  "skillRuns": [
    { "skill": "svg-asset-drawing-yashu", "gate": "G3.5", "ok": true,
      "note": "抽清单 + 定视角" }
  ],
  "decisions": [
    { "scope": "asset", "target": "turtle", "verdict": "angle-locked", "note": "背视，侧视两轮全废" }
  ],
  "costs": [
    { "kind": "image-gen", "qty": 5, "amount": 0.60, "ref": "rh2:turtle" }
  ]
}
```

### 2.3 各数组的必填字段

| 数组 | 必填 | 可选 |
|---|---|---|
| `assets[]` | `asset_key` `name` `cat` | `angle` `channel` `status` `spec_json` `note` |
| `images[]` | `asset_key` `path` | `kind` `w` `h` `prompt` `seed` `workflow` `cost` `picked` |
| `svgs[]` | `asset_key` `path` `source` | `symbol` `version` `approved` `note` |
| `artifacts[]` | `kind` `path` | `gate`（默认用顶层） `bytes` `md5` `note` |
| `skillRuns[]` | `skill` | `gate` `started_at` `ended_at` `ok` `note` `artifactPath` |
| `decisions[]` | `scope` `target` `verdict` | `note` |
| `costs[]` | `kind` `amount` | `qty` `currency` `ref` |

`cat` 只认四个值：`角色` `道具` `特效` `背景`。写别的直接报错。
`kind`（图）只认：`ref` `picked` `final` `reject`。

## 3. 幂等：重复提交必须安全

老板会重说一遍、我也会重跑一次。规则定死：

| 数据 | 去重键 | 重复提交的行为 |
|---|---|---|
| `songs` | `slug` | 更新可变字段（title/dur/bpm…），`slug` 不动 |
| `stages` | `(song_id, gate)` | 更新 status/note，不新增 |
| `assets` | `(song_id, asset_key)` | 更新 name/cat/angle/channel/status，**`asset_key` 不动** |
| `images` | `sha256`（自动算） | **静默跳过**，不报错、不改行 |
| `svgs` | `(asset_id, version)` | `version` 缺省时 +1 追加新版本，不覆盖旧版 |
| `artifacts` | `(song_id, path)` | 更新 bytes/md5/mtime |
| `skillRuns` | `run_key = sha1(slug\|skill\|gate\|started_at)` | 静默跳过 |
| `decisions` | 去重：`(song,scope,target,verdict,note)` 完全相同则跳过 | 老板重说一遍不产生新信息；判决一变就成新行 |
| `costs` | 不去重 | 同上，宁可多记不可漏记 |

**`images` 的 sha256 由程序算，payload 里不用给。** 文件读不到就报错并整批回滚（不许"先存个空 sha"）。

## 4. 事务与错误

```
开始事务
  逐条 upsert，任何一条失败 → ROLLBACK，返回退出码 2 与失败条目
提交事务 → 返回每张表的 affected 行数
```

退出码：

| 码 | 含义 | 我该做什么 |
|---|---|---|
| 0 | 全成功 | 向老板汇报行数 |
| 2 | 校验失败（字段缺失/枚举非法/文件不存在） | 修 payload 重跑，**不许跳过** |
| 3 | 引用的歌不存在 | 先 `new-song` |
| 4 | 数据库被锁（另一个进程在写） | 等 2 秒重试一次 |

**禁止**：失败后手工进库补数据。补出来的行没有 `run_key`、没有来源，属于脏数据。

## 5. 路径怎么给

payload 里的 `path` **一律相对** `D:\vibe-mv-文件库\<slug>\`：

```
✅ "images/turtle/turtle-03.png"
✅ "storyboard/relay.md"
❌ "D:\\vibe-mv-文件库\\jiaowo-laowangba\\images\\turtle\\turtle-03.png"
```

save 时程序会：① 拼绝对路径 ② 检查文件存在 ③ 算 sha256 与 bytes ④ 写库。
**文件不存在 = 直接失败**，不许存一个指向空气的路径。

---

## 6. 收工时的标准动作（我自己遵守）

1. 产物全部落进 `D:\vibe-mv-文件库\<slug>\` 对应目录
2. 组织 payload（只写这一关的东西）
3. `save` → 拿到行数
4. 再向老板汇报"存了什么、几行"
5. 如果老板说"改一下"，**重跑 save 而不是手工改库**

**顺序不许反**：没 save 就报"做完了" = 网页上看不见 = 等于没做。
