# 自进化与待办（我不问人也能往前走）

> 老板 2026-10-23 的原话：「我希望这个员工可以自进化，不要每件事都要我提醒他才去做……我希望他知道他的责任是什么，目前有哪些事情该由他去做。」
>
> 这份文件就是回答那句话的操作规程。**核心不是"更主动"，是"可推导"**——该做什么从数据里算得出来，就不靠记忆、不靠提醒。

## 1. 自检命令（一切的起点）

```
node scripts/status.mjs           人读
node scripts/status.mjs --json    给页面 / 给经理
```

它输出五块，缺一块都不算跑过：

| 块 | 回答什么问题 |
|---|---|
| 库 | 版本、表数、路径对不对 |
| 每首歌 | 关卡进度条、当前关、入库数量（文档/资产/图/定稿/SVG/二进制/调用） |
| 该我做的 | **按优先级排序的待办**，每项带"为什么" |
| 体检警告 | 文件丢失数、孤儿图数、技能表缺字段 |
| 未建模块 | 哪些文档里写了但代码还不存在（防我假装能用） |

**跑完必须能立刻说出三行结论**：现状 / 该我做 / 要你定。说不出 = 没跑懂。

## 2. 待办怎么推出来（规则表，改这里就要改 `status.mjs`）

| 数据里的迹象 | 判定 | 优先级 |
|---|---|---|
| `docs` 缺 `lyrics` | G2 的轴没入库，单歌页会空 | P1 |
| `G1=done` 但 `docs` 缺 `music` | 关卡标了完成、数据没进，属于自相矛盾 | P2 |
| `assets` 有行但 `images=0` | 图还散在旧目录，没搬进来 | P2 |
| 文件库有图但 `images` 无对应行 | 孤儿图，漏记 | P2 |
| `assets=0` 且 `G3.5≠done` | 资产清单没入库，图墙无从显示 | P3 |
| 有资产、有图，但 `picked=0` 且 `svgs=0` | 停在"等老板选图" | P4（等他，不是等我） |
| `docs` 有 `story` 但 `G5≠done` | 该装配/渲片了 | P4 |
| 登记的文件在磁盘上不存在 | 文件缺失 | P5（老板说丢了可重生成） |
| `server/` 或 `web/` 不存在 | W3 没开工 | P6 |

**改这张表的时候，`status.mjs` 必须同步改**，两边不一致等于自检在说谎。

## 3. 四个"必须自进化"的触发器

| 触发 | 我要做什么（不用问） |
|---|---|
| **老板纠正我一句话**（"commit 会误解成 git""网页必须从库读"） | 当天改文档 + 改代码 + 写进 changelog。**不留下旧做法**，也不写"已作废"挂在原地 |
| **我自己踩了坑**（DDL 里加了表、库没建、报 no such table） | 把坑写进对应章节的"注意"，并加一条可执行的防线（例：`db.mjs init` 幂等补表写进迁移节） |
| **文档与实况不符**（说 10 张表实际 11 张、列了没写的命令） | 立刻对齐。**宁可承认"还没写"，不许让文档假装能用** |
| **同一个动作我做了第三次**（第三次手工导 payload、第三次手工数某张表） | 固化成命令或 SQL 视图。第三次就是自动化的信号 |

## 4. 改动五步（顺序不许变）

1. **改文档**（`SKILL.md` 或对应 `references/`）——先定规矩，再写代码
2. **改代码**（`scripts/` / 以后 `server/`、`web/`）
3. **跑 `node scripts/status.mjs`** 与相关命令，确认新规矩真的生效
4. **写 changelog**（版本号 + 日期 + 改了什么 + 为什么）
5. **`git commit`**（一次改动一个提交，消息说清"为什么"，不只说"改了什么"）

做不到第 3 步，前两步就是空话。

## 5. 知识该写在哪（不许乱塞）

| 这类知识 | 写到哪 |
|---|---|
| 架构、职责、边界、禁令 | `SKILL.md` §0~§4 |
| 表结构、字段、索引、迁移 | `references/10-数据模型.md`（唯一 DDL 权威） |
| 写入命令、payload 字段、错误码 | `references/20-写入手册.md` |
| 页面布局、接口、空状态 | `references/30-页面规格.md` |
| 自检、待办、进化流程 | 本文件 |
| 一次性的历史细节 | `SKILL.md` 变更记录（只写结论，不写过程） |

## 6. 不许"进化"的东西（老板定的，改就是违规）

- 五条上位原则（§1）：写入口唯一、库唯一真相、大文件不进库、网页只读、页面只从库读
- 路径：库在 `D:\vibe-mv\`，文件在 `D:\vibe-mv-文件库\`
- 端口 8791；只绑 `127.0.0.1`
- 纯 JS、零依赖、无构建
- 数据一律经 `cli.mjs save`，没有第二个写入口

这些要改，只能老板说，我不能自己"优化"。

## 7. 每次收工的三问（写在汇报之前）

1. **入库了吗？** 没 `save` 就等于没做（老板打开网页看不见）。
2. **自检过了吗？** `status.mjs` 里我这一关的迹象消失了吗？
3. **文档还准吗？** 这次有没有新增"文档说 A、代码是 B"的裂缝？

三问有一问答不上，就先别汇报。
