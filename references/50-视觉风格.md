# 视觉风格（产品经理定的，实现照做）

> 定稿人：经理（产品）｜ 2026-10-23 ｜ 实现：`vibe-mv-studio-yashu`
> 这份文件管"长什么样"，`30-页面规格.md` 管"放什么东西"。两者冲突时以本文件的**审美判断**为准，以 30 的**信息取舍**为准。

## 0. 一句话定位

**这是一本纸样册，不是一块仪表盘。**

老板打开它，99% 的时间在做三件事：**看图、看词、看进度**。所以整个界面要退到内容后面去——纸白底、细线、无阴影、数字用等宽，让白底的剪纸图自己跳出来。

**反过来说：凡是让人先注意到"界面很漂亮"的设计，都是错的设计。**

## 1. 一个隐喻：纸

引擎叫 `flatpaper`（纸片），资产是**白底扁平剪纸图**。界面跟着纸走，有三个直接好处：

| 好处 | 为什么重要 |
|---|---|
| 白底图放在米白纸上，边缘不刺眼 | 深色仪表盘会把每张图变成一块发光白砖，看 20 张眼睛就累 |
| 细线代替阴影，层次靠留白和分隔线 | 老板不是在"操作 App"，是在"翻样本" |
| 颜色极少，只有一处红 | 红色只留给"该我做的"和"当前关"，一屏只出现一次 |

## 2. 色彩（一共 8 个值，不许再加）

```css
--paper:      #FAF8F3;  /* 页面底：暖纸白 */
--paper-hi:   #FFFDF8;  /* 卡片/表头底：更亮一档，靠这点差分层 */
--ink:        #2C2C2A;  /* 正文 */
--ink-2:      #5F5E5A;  /* 次要信息、单位、说明 */
--ink-3:      #8A8880;  /* 占位、禁用 */
--rule:       #E4E0D6;  /* 唯一的分隔线色（0.5px 或 1px） */
--seal:       #A32D2D;  /* 印泥红：只给「该我做的」和「当前关」 */
--done:       #3B6D11;  /* 已过闸 */
--draft:      #185FA5;  /* 完整待点头 */
--partial:    #854F0B;  /* 有产出不完整 */
```

> 状态四色（done/draft/partial/todo）**只出现在小圆点、细描边和数字上**，不许大面积填充。
> `todo` 不用颜色，用 `--ink-3` 的灰。

**禁止**：渐变、玻璃拟态、彩色大面积色块、阴影、发光、暗色主题（P0 不做）、任何"品牌渐变色带"。

## 3. 字体与数字

| 用途 | 规格 |
|---|---|
| 中文 | `system-ui, "Microsoft YaHei", sans-serif`，正文 13px / 行高 1.6 |
| 标题 | 15px，**只用一个字重 500**。不用 700，不做花字 |
| 数字 | `ui-monospace, Consolas, monospace` + `font-variant-numeric: tabular-nums`。BPM、时长、字节、成本、句数全部走等宽 |
| 英文/路径 | 同上等宽，11–12px，`--ink-2` 色 |
| 字距 | 小标签（"该我做的""流水线"）用 `letter-spacing: .08em` + 11px，全大写感但用中文 |

**数字必须右对齐**（表格里），单位用 11px 的 `--ink-2`，不参与对齐。

## 4. 布局与密度

```
┌──────────────────────────────────────────────┐
│ 工作室 · 叫我老王八            刷新索引  ──── │  56px 顶栏，底边一条 0.5px 线
├──────────────────────────────────────────────┤
│ ● 该我做的 · 1                               │  一条红，只有这里
│   资产清单还没入库            [开始]          │
├──────────────────────────────────────────────┤
│ 流水线  G0●─G1●─G2●─G3○─G3.5○─G4○─G5○       │  一行，不许换行
├──────────────────────────────────────────────┤
│ 文档 3      资产 0      图 0      调用 2     │  四个数字并排，不做卡片盒子
├──────────────────────────────────────────────┤
│ 内容区（单页正文）                            │
└──────────────────────────────────────────────┘
```

| 规矩 | 值 |
|---|---|
| 内容区最大宽 | **1280px** 居中；图墙页可到 1600 |
| 最小可用宽 | 1100px（不给手机做，老板只用桌面 Edge） |
| 区块间距 | 竖向 24px 一档，不许出现 32/40/48 混排 |
| 一屏必须能看到 | 待办 + 七关 + 关键数字 + 第一屏内容 |
| 禁止 | 大留白 hero、居中大标题、欢迎语、"开始使用"引导 |

**为什么这么紧**：老板一天要开十几次，每次只想确认"变了没有"。紧的界面 = 一眼扫完；松的界面 = 每次多滚两屏。

## 5. 组件规矩

| 组件 | 怎么画 |
|---|---|
| **卡片** | 圆角 6px，1px `--rule`，底 `--paper-hi`，**无阴影**。只有"一张图/一件资产"才配用卡片，普通内容用分隔线 |
| **表格** | 无斑马纹，无竖线，只有行间 0.5px 横线；表头 11px `--ink-2`；数字右对齐 |
| **图墙** | 每格 4:3 或原比例**不裁切**，`object-fit: contain`，格子底纯白（`#FFFFFF`）与纸白区分；文件名 11px 等宽压在格底，hover 才显示提示词/seed |
| **播放器** | 16:9 黑底取景框（这是全站唯一允许的深色块），边不留圆角，配一条 30px 的自绘进度 + 拍点刻度 |
| **关卡条** | 七个圆点 + 细连线，done 实心、current 空心套红、todo 空心灰；标签在点下方 11px |
| **待办行** | 左边 2px 印泥红竖线，右边一个方角按钮。**全站唯一允许的实心按钮就在这里用** |
| **按钮** | 其余地方一律：透明底 + 1px `--rule` 边 + 6px 圆角，hover 只把边加深 |
| **空状态** | 一句话说清"缺什么" + 一个动作（"去入库""等老板选图"）。**禁止插图、禁止"暂无数据"四个字打天下** |

## 6. 动效

只有三种，别的一律不许：

1. hover：`border-color` / `background` 变化，**120ms**，不做位移
2. 进度条：宽度过渡 300ms
3. 页面切换：不做转场，直接换

**禁止**：弹窗动画、骨架屏闪光、数字滚动、卡片浮起、`transform: scale`。

## 7. 单歌页的特别规定（最重要的一页）

三栏，固定比例 `260px | 1fr | 320px`：

| 栏 | 内容 | 风格要点 |
|---|---|---|
| 左：歌词轴 | 7 句，逐字 | 当前句实心墨色、其余 `--ink-3`；时间码 11px 等宽右对齐；**播放时按 `words[].t` 高亮单字**，高亮用印泥红不加粗 |
| 中：内容区 | 六关堆叠，每关一块：音频/分镜正文/图墙/片 | 关与关之间只隔一条 0.5px 线，不折叠、不做 Tab |
| 右：检查器 | 当前选中对象：资产名、图、提示词、seed、成本、路径 | 键值对两列，键 11px `--ink-2`，值等宽；路径可复制但**不可点开** |

## 8. 三条自检（实现完自己看一遍）

1. **眯眼测试**：眯眼看页面，唯一该跳出来的是红色那条待办；跳出来两个以上红色 = 用色超标。
2. **截图测试**：截一张图给老板，他第一眼看到的是图/词/数字，不是导航和边框 = 风格对了。
3. **删色测试**：把红色临时改成灰，页面还成立吗？成立 = 颜色用得克制；全塌了 = 你把颜色当结构用了。

## 9. 与其它台子的关系

打轴台（8787）、审核台（8788）已经存在，本台**不要求和它们长得一样**，但要求同一套"密度与克制"：无阴影、少颜色、数字等宽。三个台子并排开着时，不能让人一眼看出是三家公司的产品。
